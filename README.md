# OrangeBox Dictation downloads

Signed preview installers and update feeds for OrangeBox Dictation.

Download the Apple Silicon or Intel DMG from the latest numbered release.
The `updates` release contains metadata used by the built-in updater.

The development repository and its history are private. App downloads include
compiled native code and the bundled Python engine; no recordings, settings,
vocabulary, models, or credentials are included.

Preview builds are ad-hoc signed and not notarized by Apple.
